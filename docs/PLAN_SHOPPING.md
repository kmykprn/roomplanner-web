## P2: 楽天の商品 URL から取り込む

### 流れ

```
家具タブ「商品の URL から作る」
  → URL を貼る
  → API 層 POST /products { url }         … 楽天の公式 API で商品情報と画像を取る
  → 返ってきた画像を既存の切り抜き（cutout）に通す
  → 保管庫に「商品情報つき・実寸つき」の家具として入る
```

### サーバー（Hunyuan3D-2GP の API 層、CPU）

- `POST /products`（JSON `{ "url": "https://item.rakuten.co.jp/{shop}/{code}/" }`）
  - Firebase の ID トークン必須。許可リストは見ない。uid ごとに 1 日 200 回
  - 対応するのは `item.rakuten.co.jp` の商品ページだけ（許可リスト方式。他は 400）。
    URL から `shop:code` を作り、**楽天市場商品検索 API**（公式）に `itemCode` で問い合わせる
  - 楽天 API は `applicationId` と `accessKey`（2026 年版から必須）、`affiliateId` を使う。
    3 つとも Terraform の変数（sensitive）→ Cloud Run の環境変数。**Git には置かない**
  - 返すもの: `{ name, price, shop, url, affiliateUrl, image: <base64>, size: {w,h,d} | null }`
    - 画像は API の `mediumImageUrls`（128px）の URL を大きいサイズに書き換えて（`_ex=1024x1024`）
      サーバーが取得し、画像として読めることを確かめてから base64 で返す（ブラウザから楽天の
      CDN を直接取れないため。5MB 上限）
    - 寸法は `itemCaption` / `itemName` から「幅○cm 奥行○cm 高さ○cm」（W/D/H、mm、約、× 区切りも）を
      正規表現で拾う。取れなければ null（クライアントは既定の 1m で置く）
  - 楽天 API の 429 はそのまま 429 で返す（「少し待ってから」）
- テスト: 楽天 API を偽物にして、URL の解析・寸法の抽出・画像の検証・回数

### クライアント（roomplanner-web）

- 家具タブに「商品の URL から作る」。URL の入力欄（貼り付け）→ 取り込み中のサムネイル → 切り抜き → 保管庫へ
- `GeneratedModel.product?: { shop, name, price, url, affiliateUrl, size }`。置いた家具にも写す
- 寸法が取れた家具は `size` を実寸（m）にする。取れなければ従来どおり 1m
- サムネイルの名前は商品名の先頭（例「北欧 2人掛けソファ…」）。編集の姿で価格と店名を出す

## P3: 「楽天で見る」（アフィリエイト）

- 家具のサムネイル・編集の姿・操作タブに「楽天で見る ¥24,800」。押すと **外部ブラウザ**で `affiliateUrl` を開く
  （`target=_blank` + `rel=noopener`。アプリ内 WebView は成果が付かないことがある）
- 画面上の案内（ボタン横の文言・初回ダイアログ）は**出さない**。うちは商品を推薦していない（貼るのは本人）ので、
  ステマ規制の「広告と分かる表示」の義務には当たらないと判断した
- ただし楽天アフィリエイトの規約は利用の明示を求めるので、**利用規約 / アプリ情報に 1 行**だけ書く:
  「商品ページへのリンクに楽天アフィリエイトを利用しています。購入により運営者が紹介料を得ることがあります。価格は変わりません」
  文面は登録時に楽天が求める表現に合わせる
- 計測はまず楽天アフィリエイトの管理画面（クリック数・成果）に任せる。自前の記録は要るようになってから

## あなたにやってもらうこと

1. 楽天アフィリエイトの登録（サイト URL `https://kmykprn.github.io/roomplanner-web/`）→ **アフィリエイト ID**
2. 楽天ウェブサービスでアプリを作成 → **アプリ ID** と **アクセスキー**
3. 3 つの値を `Hunyuan3D-2GP/infra/terraform.tfvars`（gitignore 済み）に書く。
   チャットにも Git にも貼らない（アクセスキーは秘密）

```
rakuten_application_id = "…"
rakuten_access_key     = "…"
rakuten_affiliate_id   = "…"
```

## 見送り・注意

- Amazon（PA-API は成果実績が先に要る）、IKEA・ニトリ（公式 API 無し）は後回し
- iPhone の Safari は Cookie が短命なので、成果は控えめに見積もる
- 商品画像の著作権: 楽天 API の利用規約の範囲（商品紹介目的）で使う。取り込んだ画像は端末にだけ置き、サーバーには残さない
